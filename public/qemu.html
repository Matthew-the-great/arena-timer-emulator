Load real firmware

No firmware is bundled. First upload a complete 4 MB ESP32 flash image containing the bootloader, partition table and application. Later, an application-only .bin can update the first application partition while preserving saved settings. Stop QEMU before loading.

This writes actual virtual flash. It is a bench programmer, not ElegantOTA. CPU execution after boot depends on firmware compatibility with QEMU’s implemented peripherals.
